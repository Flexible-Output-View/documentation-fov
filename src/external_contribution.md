# Acknowledgements to Contributors

## Purpose of This File

This file aims to **thank and credit external contributors who have participated in the development of Flexible Output View (FOV)**.

It helps keep a record of external contributions received, the work carried out, their review process, and their integration into the project.

In the context of this contribution, an external contribution is considered valid when it corresponds to a code modification, a documentation correction, a translation, the addition of tests, a properly documented bug report, or an external code review.

This document presents the **external contributions received, reviewed, and integrated into the `dev` branch**, as well as the contributors behind them.

---

## External Contributions

### Hugo Payet — @SizzleUnrlsd

**Project:** `web-fov`
**Pull Request:** `#108 — ci: ADD backend and frontend coverage reporting`

Hugo Payet, under the GitHub username **@SizzleUnrlsd**, contributed to the `web-fov` project by working on the implementation of backend and frontend test coverage tracking.

Pull Request #108 notably included the following commits:

- `ci(coverage): ADD backend and frontend coverage reporting`

- `fix(frontend): FIX stream availability filtering`

The Pull Request was then reviewed by the group members. **RaphxelS** performed a review and approved the changes, after which the Pull Request was merged into the `dev` branch.

**Thank you to Hugo Payet (@SizzleUnrlsd) for this contribution and for his work on improving the project's quality tracking.**

### Maël-Mamadou Diagne — @Mogza

**Project:** `obs-studio-fov`
**Pull Request:** `#51 — UPDATE: About.Info to introduce FOV as a fork in italian language`

Maël-Mamadou Diagne, under the GitHub username **@Mogza**, contributed to the `obs-studio-fov` project by adding the Italian translation of the `About.Info` section.

This contribution followed issue **#28 — FOV about page translation**, which requested localizing the content of `About.Info` into the different languages supported by the application.

The contribution added the Italian language file `it-IT.ini` and adapted the FOV presentation text into Italian.

Pull Request #51 included a modification of the localization file, and the **5 automated checks were validated**. It was then reviewed, approved, and merged into the `dev` branch.

**Thank you to Maël-Mamadou Diagne (@Mogza) for this contribution and for helping make FOV accessible to Italian users.**
