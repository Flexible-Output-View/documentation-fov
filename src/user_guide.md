# User Guide

Welcome to the FOV User Guide! This section provides everything you need to set up your environment, configure the custom FOV OBS Studio build, and start broadcasting interactive multi-track streams.


## Table of Contents

- **[Installation](./user_guide/installation.md)**
  Step-by-step instructions to download, set up, and configure the custom FOV software required for broadcasting.

- **[Start a Stream](./user_guide/start_a_stream.md)**
  A comprehensive walkthrough covering technical constraints, service configuration, hardware encoder choices, and going live on [fovapp.live](https://fovapp.live) (or your self-hosted instance).

- **[Configuring streaming settings](./user_guide/stream-settings.md)**
  Learn how to optimize multi-track video and audio encoding, manage bandwidth scaling, and switch between Simple and Advanced Output modes.

- **[Local multitrack recording](./user_guide/multitrack_recording.md)**
  Capture isolated video and audio tracks locally into Hybrid MP4/MOV containers for multi-stream playback and post-production editing.
